2. Le service proposé

Bibi Quizz est un jeu de culture générale accessible dans un navigateur. L’organisateur ouvre le plateau sur un écran, puis chaque participant rejoint le salon avec un code sur son téléphone. Les manches associent rapidité, réponses chronométrées et duel à indices. Un animateur peut valider les réponses orales ; le mode clavier propose une correction automatique avec arbitrage de l’organisateur.
